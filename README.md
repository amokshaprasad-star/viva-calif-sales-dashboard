# Viva Calif Sales Performance Dashboard

![Dashboard preview](dashboard.png.png)

## Overview
An Excel dashboard summarising orders, sales, units, ratings and delivery for a California apparel business.

**Tools:** Excel, Pivot Tables, Slicers

## Dataset
2,400 orders.

## What I did
- Summarised orders, sales, units, average rating and delivery time.
- Visualised the 13-week sales trend, top products, order method by gender and a California customer map.
- Tracked shipping time and monthly ratings (January to March).
- Added Order Method and Gender slicers that filter all charts.

## Key insights
- 2,400 orders, $649.02K sales and 11,997 units.
- Average rating 3.96 and average delivery time 2.3 days.
- T-shirts are the most popular product, followed by jeans and sneakers.
- Two items is the most common order size (540 orders).
